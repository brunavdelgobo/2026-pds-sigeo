# 📐 Diagramas — SIGEO

## 📌 Sobre esta pasta

Esta pasta reúne os diagramas desenvolvidos para a modelagem e documentação do sistema SIGEO — Sistema de Gerenciamento de Empréstimo de Objetos.

Os diagramas representam diferentes aspectos da estrutura, dos processos e do funcionamento do sistema, auxiliando na compreensão e no desenvolvimento da solução.

## 📂 Diagramas presentes

- **5 diagramas de casos de uso** — representação das funcionalidades do sistema e da interação dos usuários com o SIGEO.
- **1 diagrama de classes** — representação da estrutura das classes e seus relacionamentos.
- **1 diagrama de banco de dados** — representação das entidades, atributos e relacionamentos do banco de dados.
- **3 diagramas de atividade** — representação dos fluxos e processos realizados pelo sistema.
- **3 diagramas de sequência** — representação da interação entre os componentes do sistema ao longo do tempo.
- **1 diagrama de metodologia** — representação da organização dos componentes e da infraestrutura necessária para o funcionamento do sistema.

## 🛠️ Ferramenta utilizada

Os diagramas foram desenvolvidos utilizando o **draw.io**, mantendo os arquivos editáveis e suas respectivas exportações para visualização.
