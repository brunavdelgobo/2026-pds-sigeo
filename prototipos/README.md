# 🎨 Protótipos — SIGEO

## 📌 Sobre esta pasta

Esta pasta reúne os protótipos desenvolvidos para representar visualmente as principais telas do sistema SIGEO — Sistema de Gerenciamento de Empréstimo de Objetos.

Os protótipos foram desenvolvidos para definir a estrutura visual e a organização das interfaces do sistema, servindo como referência para o desenvolvimento da aplicação.

## 📂 Protótipos presentes

- **Tela de Cadastro** — protótipo da interface utilizada para realizar o cadastro no sistema.
- **Tela Inicial** — protótipo da página principal do sistema e de suas principais funcionalidades.
- **Tela de Usuário** — protótipo da interface relacionada às informações e funcionalidades do usuário.

## 🛠️ Tecnologias utilizadas

Os protótipos foram desenvolvidos utilizando **HTML e CSS**, com auxílio do **Visual Studio Code (VS Code)**.
